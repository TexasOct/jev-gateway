# Dashboard 中英文界面

## Goal

让 dashboard 的监控和策略配置界面支持中文与英文，并允许用户在界面内切换语言。

## Confirmed facts

- 前端为 `frontend/` 下的 React/Vite 应用，静态资源由网关提供。
- 界面文案目前散落在 `frontend/src/App.tsx` 和 `frontend/src/config/RoutingEditor.tsx`，日期格式使用浏览器默认语言；`frontend/index.html` 当前为 `lang="en"`。
- 现有安全约束要求 API 凭证只保存在浏览器内存。`tests/test_gateway.py` 当前禁止构建产物使用浏览器持久化存储 API；本任务将其精确调整为只允许固定 locale key，并保留对凭证持久化的禁止断言。

## Requirements

- 监控、配置、状态、错误提示、按钮、空态、表头、输入占位和无障碍名称均随所选语言切换。
- 数值、时间展示匹配所选语言；策略名、模型 ID、JSON 证据字段和服务端原始数据保持原值。
- 切换语言不丢失认证状态、选中的会话或未保存的配置草稿。
- 将用户选择的语言偏好保存到浏览器，以便刷新或再次打开页面后沿用；持久化数据仅限固定键下的 locale 标识，绝不保存凭证。
- 与监控列表及 workflow 画布的界面改造共用一套翻译接口，避免重复修改即将被替换的文案。

## Acceptance criteria

- [ ] 用户可在 dashboard 切换中文和英文；手动选择的语言在刷新和再次打开页面后保留。
- [ ] 两种语言覆盖监控与策略配置主要 UI，以及动态提示和无障碍名称。
- [ ] 时间按当前语言格式化，底层 API 枚举、配置值和证据数据不被翻译。
- [ ] 切换时未保存草稿与选中状态保留；凭证始终只在内存中，浏览器持久化仅包含 locale 标识。
- [ ] 词条完整性、切换行为与前端构建检查通过。

## Out of scope

- 翻译模型输出、用户请求内容及留存证据 JSON。
- 更改后端返回的错误文本或 API 枚举契约。
