# 设置供应商与模型页面样式迁移

## Goal

统一设置、供应商及其模型列表、模型编辑和批量导入的组件与页面呈现，保留现有功能入口和写入契约。

## Requirements

- 对应父任务 R3-R8；采用已验收的共享组件和主题约定。
- 整理表单分组、说明/错误层级、列表密度、按钮位置、留白和窄屏排列。
- 保留凭证 keep/set/clear、保存失败草稿、权限与原子事务、模型三态/来源/手动覆盖和导入确认。
- 模型继续位于所属供应商下，保持搜索/切换/关闭/写入保护和可达焦点。

## Acceptance Criteria

- [x] C1：覆盖矩阵中的设置/供应商/模型控件与页面一致，父任务 A2/A3。
- [x] C2：主题、凭证、模型修改与批量导入关键流程回归通过，无额外写入、草稿丢失或跨供应商串数据，父任务 A4/A5。批准的 E1 原生 select popup-first Escape 仍为 UNVERIFIED。
- [x] C3：中英文/明暗、桌面/390px/320px 的代表性界面和编辑弹窗可用，footer、错误与动作可达，父任务 A7。
- [x] C4：本阶段所需局部检查通过，覆盖保留项有记录；父任务 A8 完整稳定源码集成检查仍由最终集成负责。

独立 Config 审查已接受上述批准范围，证据见 `check-handoff.md` 与 `research/check-audit.json`。实现报告恢复的交付结果不代替产品验收；E1 未被证明通过。

## Dependencies and exclusions

- 等 Primitives P1-P3 验收；Foundation 为传递依赖。
- 不编辑共享依赖/token/primitive，不改变 API、证据匹配、模型身份或导航归属。
