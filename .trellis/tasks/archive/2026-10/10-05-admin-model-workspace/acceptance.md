The independent test asserts the actual upstream ID and fails. `prefillMetadata` stores its item as `draft.evidence`; it does not rewrite nested source IDs. `withConfirmedMetadata` derives persistence from metadata sources, so this evidence establishes a displayed/current-evidence target inconsistency, not a demonstrated persisted source-ID corruption. There is no `capturedUpstreamID` property in this integrated ModelDraft implementation. Owner: model UI. Owner: shared Dialog/model UI. Fixes must preserve native interaction and add coverage from initial focus, without weakening this assertion. Background interactivity itself was not demonstrated; the verified defect is focus leaving the modal subtree.
