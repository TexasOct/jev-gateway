# 策略工作流中文文案与画布连线编辑

## Goal

让操作者在策略工作流画布中看清节点职责、输入与输出方向，并直接选择、连接、改接和断开连线。节点的输出端口数量与当前输出选项保持一致，选项增减后仍能清楚操作。

## Background

用户已明确要求创建任务、设计开发，并通过当前 Goal 授权自主实现和验证。现有页面以 React、TypeScript 和 Tailwind 实现，画布布局单独保存，策略修改经过草稿、校验、审阅、应用流程。

## Requirements

- R1：统一策略工作流页面的中文标题、节点类型、工具、提示、编辑与校验文案；保留配置中的模型、标签、问题及选项标识。
- R2：问题、规则、兜底、标签池和模型节点拥有清楚的职责标识，文字、图标和内容行对齐；提供可用的节点对齐操作。
- R3：输入端口显示在节点左侧，输出端口显示在右侧，配套方向与分支名称。起点和终点分别按真实能力显示端口。
- R4：画布支持直接选择连线、查看来源与目标、选择目标进行连接或改接、断开可编辑连线；鼠标与键盘都能完成。不可执行的操作须显示具体原因。
- R5：按当前输出选项生成端口，增减输出选项后端口同步增减；密集节点扩展高度并维持可点击间距，端口与线端保持对齐。
- R6：连接编辑进入策略草稿并遵循现有校验、审阅、应用机制。移动、对齐、缩放等布局操作只保存画布布局。
- R7：规则和失败兜底可先断开标签输出，显示未连接端口后重新选择标签；未补全的草稿不能应用。有效 choice 问题的选项端口显示判定结果通往规则入口，仍按原有顺序执行全部规则。不支持的问题类型、少于两个选项或空选项说明给出具体提示并阻止审阅。
- R8：准确区分判定成功但规则均未命中的策略默认路径，以及判定失败时的已配置兜底路径。无规则时同样保留这两条不同路径。

## Constraints

- 保持现有有序规则首个匹配、未命中继续、最终使用策略默认标签及选择模式的运行语义；判定失败使用配置的 fallback。
- 显式模型列表标签池与最后一个模型的保护沿用配置能力；问题入口、未命中规则链等固定连线说明限制，不能把不完整图伪装为有效策略。
- 浏览器验证使用合成配置与独立测试服务，不调用真实模型上游，不编辑操作者的运行配置。
- 工作区已有 `.trellis/tasks/10-03-dashboard-gateway-key-page/` 为其他任务，本任务不得包含或覆盖其内容。

## Acceptance Criteria

- [x] AC1：中文界面文案完整且一致，英文界面仍可用。
- [x] AC2：五类节点均能辨认，长名称不覆盖图标或端口，对齐操作后节点位置可保存与恢复。
- [x] AC3：浏览器实际渲染可见左输入、右输出，连线锚点对应端口中心。
- [x] AC4：真实鼠标操作可选择连线、连接或改接到合法目标、断开模型池及规则/兜底标签连线；断开标签后可以从保留的空端口重新连接。键盘完成等价操作，取消和非法操作均有反馈。
- [x] AC5：输出数量增加、减少与密集输出案例具有对应端口、无重叠且可操作；布局计算、框选、拖拽、Fit 与检查器使用相同节点几何。
- [x] AC6：草稿编辑不提前应用策略，对齐/移动不调用策略写入；校验、审阅、应用以及只读限制保持有效。
- [x] AC7：lint、类型检查、单元测试、浏览器回归、后端回归和构建时效检查通过；保留截图与逐项验收证据。
- [x] AC8：兜底与默认标签/选择模式不同时，文案、画布及路径预览仍与真实后端行为一致；包括有规则未命中、零规则和判定失败。
- [x] AC9：累计节点高度超过坐标范围时分列或报告超限，257 个节点及字节超限时反馈可达且不破坏最后保存布局。已保存位置在输出增长后仍可恢复，整理布局能消除重叠。

## Scope

本任务包含策略工作流文案、节点与端口呈现、画布连线编辑、自动扩展端口与对齐操作，以及必要的文档和验证。监控、Provider、连接 Key 页面和后端路由算法的扩展不属于本次需求。
