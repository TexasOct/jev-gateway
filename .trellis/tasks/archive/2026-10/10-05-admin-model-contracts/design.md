# Design

Follow `../10-05-admin-experience/design.md` contracts exactly. Own backend catalog/provider_config/model_metadata/discovery/gateway changes and shared frontend types/client API. Add `update_model` within existing expected_revision transaction and optional ImportModel display_name/enabled/cache cost fields. Avoid overwriting effective overlay membership while updating baseline model records. Preserve identity or explicitly reject renaming that would break references.

Connection test accepts existing LLM selector, reports bounded model-list validation scope and returns semantic statuses with safe fixed public errors. Reuse existing validated-IP/redirect/timeout handling. Decision protocols without a safe listing probe remain explicitly unsupported/configuration-only. Read actual public source schema using authoritative documentation and persist evidence URLs; do not invent price/capability inference.

The existing primary-only credential operation cannot complete native-cloud direct entry. LLM upserts and candidate selectors accept optional `transport_credentials: Record<parameter, CredentialAction>`, restricted to declared `param_env` bindings. Safe reads expose optional `transport_credential_presence` booleans. SET/KEEP/CLEAR share the protected JSON/dotenv owner, revision and rollback. Exclude only the edited binding from shared-reference counts and recheck the completed candidate, including same-provider and later-operation consumers. Candidate actions never persist or mutate process environment. Keep omitted-field compatibility and do not return transport secret values.
