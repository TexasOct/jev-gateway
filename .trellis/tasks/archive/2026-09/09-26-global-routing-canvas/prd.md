# 重构策略配置为全局画布

## Goal

将路由策略编辑改为以全局画布为主的工作区，减少固定侧栏对画布的挤占，让节点详情可按需查看，并保留独立于策略的画布布局配置。

## Background

当前策略工作区把画布和节点属性并排放置，窄视口下画布空间有限，节点属性表单较长。仓库已有独立的 `routing-canvas-layout.json` 及 `/v1/dashboard/canvas-layout` API，用于保存节点坐标与滚动画布视口；策略变更仍走独立的草稿、校验、审核和应用流程。

## Requirements

- 顶部通用导航、主题和语言控件保持独立；其下剩余页面空间全部作为同一画布工作区，宽高随可用视口变化。实际画布填满工作区，不能只扩大外层卡片而仍保留固定高度的内嵌白板或底部大片闲置区域。
- 策略标题、状态和警告以工作区内的紧凑控件呈现。帮助、节点/连接列表、高级信息和待处理变更集中到工作区底部默认折叠的信息抽屉；展开内容在受限区域内滚动，审核、取消及恢复入口仍可访问。
- 常用操作采用画布上的悬浮按钮栏呈现，参考 Excalidraw 的工具栏交互。至少包含新增规则节点（沿用问题、判定项和标签选择流程）和切换画布工具/编辑模式的入口；模式是画布交互状态，不切换后端路由策略，也不改变策略执行语义。具体可用操作随当前策略及选中状态变化。
- 节点属性浮窗锚定在选中节点附近。浮窗具有最大宽高，内容超出时在浮窗内部滚动；靠近画布边缘时自动调整位置，保证浮窗处于可视范围内。小屏幕下仍可访问和操作。
- 节点整体可拖动；点击查看详情与拖动排布应清楚区分。拖动期间浮窗不挡住指针或导致画布跳动，缩放/平移后的位移与实际坐标一致，多选移动保持相对距离，取消手势不保存。提供可辨识的拖动状态与坐标反馈。
- 问题、规则、回退、标签池和模型节点分别有明确类型标记、图标和不同的边框/色调，不仅靠颜色区分。节点展示类型、标题及一行紧凑摘要，完整内容仍在浮窗中查看；适配浅色/深色主题及中英文。
- 保存节点在画布中的相对布局（坐标及适用的视口信息）到独立布局配置，不得写入实际路由策略配置或影响策略版本、哈希、加载及策略语义。
- 保持现有策略草稿、校验、审核、应用、取消/恢复流程和现有策略行为。
- 保持布局读取失败时默认布局可用，布局保存仍受现有鉴权和校验约束。

## Acceptance Criteria

- [x] 通用顶栏以下的剩余视口由同一个工作区及其实际画布填满；在高屏、普通桌面和窄屏下均无固定高度白板造成的大块闲置空间。
- [x] 策略标题、提示、工具栏、节点浮窗、底部折叠抽屉和审核操作均处于同一工作区内部；展开抽屉不会把审核操作推到页面远端，长内容可内部滚动。
- [ ] 选中节点时，属性浮窗锚定在节点附近；浮窗尺寸受限，长内容在浮窗内滚动，靠近边缘时保持在可视范围内。
- [x] 画布悬浮操作栏可切换画布交互模式，并提供添加节点入口；所选模式有可辨识的状态和键盘操作，不引入多策略选择，适配窄屏。
- [ ] 不选中节点或关闭详情后可恢复完整画布操作；键盘和窄屏操作可用。
- [ ] 单节点/多节点在缩放与平移后均能准确拖动，拖动中不会因详情浮窗或视口重定位而跳动；取消手势恢复起点且不写入，显示布局保存失败时不误报成功。隔离浏览器复核验证了组拖动、Escape/指针取消和单次保存失败回退；后续发现并发保存失败及滚轮拖动竞态，代码已修复并有 10 个新回归用例，仍需复测这两种浏览器时序。
- [x] 移动节点后布局写入独立配置，重载后位置恢复；布局数据不含策略规则正文或连接，也不改变策略 overlay、策略哈希/版本和运行行为。隔离浏览器在桌面及 320px、0.75/1.0 倍缩放验证真实指针拖动，并确认布局 PUT 与刷新后未缩放坐标恢复；非零缩放视口的规范化视口请求和重载亦通过。
- [x] 五类节点通过类型文字、图标和边框/色调可区分；选中、拖动、只读和连接目标状态不会混淆，长模型名不撑破节点或覆盖端口。SSR 测试覆盖标签和内容；隔离浏览器截图确认 Questions/Rule 的标题、类型、摘要和边框处理可见，端口仍在原位置。
- [x] 布局接口鉴权、输入校验、默认布局与损坏数据回退保持有效。
- [ ] 现有策略编辑与审核/应用流程无回归；布局操作不会产生待审核策略变更。
- [x] 中英文界面均提供对应文案。

## Out of Scope

- 改变路由策略语义、节点/连接兼容规则或执行顺序。
- 多人协作、按用户隔离布局或新增策略自动生成能力。
- 本次不扩展到多策略编辑、策略级布局隔离或路由配置 API 改造。
