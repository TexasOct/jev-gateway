3. Apply only the reviewed pinned dependency, configuration, alias and token changes. Preserve original source/reset and existing utility.

6. Run root commands `npm --prefix frontend run lint`, `npm --prefix frontend run test`, `npm --prefix frontend run build`. After build, run appearance/connection/auth browser checks from `frontend/` using `npm exec -- playwright test -c playwright.config.ts` with the affected suite paths.
7. Record F1-F3 receipts and deliver a stable CLI/alias/token contract to primitives. Revert only this slice if checks fail.

Do not run a live config write, framework migration, broad reset or publication. Generated dashboard assets stay ignored.
