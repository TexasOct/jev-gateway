# shadcn 官方工作流与主题接入

## Goal

建立可重复使用的官方 shadcn/ui 工作流和语义主题基础，使组件可通过 CLI 添加并兼容现有蓝色、自定义种子色与明暗模式。

## Requirements

- 对应父任务 R1、R4、R8；仅在父任务完整方案获批后实施。
- 使用 npm、固定版本 CLI、components.json 和可解析别名，组件源码与许可由项目管理。
- 保留现有单一 CSS 入口、Tailwind v4、动态调色板及主题读写契约，不引入远程资源或主题持久化。
- 保留并重新核对其他会话的依赖、Dialog、shell 和验收修改。

## Acceptance Criteria

- [ ] F1：隔离副本中 CLI 可预览/添加组件，生成路径正确，源码及导入可构建，对应父任务 A1。
- [ ] F2：语义 token 完整且主题读写/重置、蓝色默认、已保存自定义色、系统/明暗继续有效，对应 A4。
- [ ] F3：流程文档和许可完整，lint/unit/build 与相关主题/连接浏览器检查通过，对应 A8。

## Dependencies and exclusions

- 前置：最新共享源码与原任务相关修复/验收状态核对。
- 下游：共享组件子任务仅消费本任务已验收的 CLI、目录与主题约定。
- 不迁移业务页面，不改变后端 API、真实配置、默认种子色或发布版本。
