## Retained qualification evidence

The initial source browser command passed 241 cases and skipped two cases that
needed local credential services. A later complete source run supplied those
services and passed all 243 cases without retries. The initial partial result and
fixture setup failures remain in the private evidence.

The first public browser attempt stopped before test discovery because
`PYTHONSAFEPATH=1` hid the private helper module. The driver now loads that helper
from its own directory explicitly. Test assertions and retry policy are unchanged.

Both public installation commands exited 0 and produced successful product
receipts. Their additional cleanup audit initially rejected a plain bind on a
recently used macOS TCP port. A separate cleanup check confirmed no listener, no
owned service or PID record, removed executables and a successful listening bind
with `SO_REUSEADDR`. The original failed audit remains intact.

The local preview wheel and public wheel have separate archive identities.
Their Python files, templates, application JavaScript and 39 SVGs are identical.
The local stylesheet contains additional generated utility selectors and differs
from the CI stylesheet, so local browser evidence does not substitute for the
installed public browser gate. The published wheel matches the CI artifact exactly.

Native command logs, checksums, installation provenance, preserved runtime files,
browser reports and source/index snapshots remain under the private
`.git/jev-release-012/evidence/` directory. This report contains counts and public
identifiers only; credential values, runtime records and captured request data
