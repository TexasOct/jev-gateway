# JEV Gateway 0.1.10

This release clarifies automatic workflow-layout saving in the routing editor.

- The workflow review action displays a spinner and “Saving…” while the canvas
  layout is being persisted, instead of showing an unrelated strategy-review
  message.
- The canvas no longer presents a duplicate layout-saving status alongside
  the review action.
- The review action remains disabled until layout persistence completes.

The release also includes the decision-routing and model metadata capabilities
from 0.1.9. See [0.1.9 release notes](v0.1.9.md).

Python 3.12+ is required. The installed wheel includes the Dashboard and needs
no Node.js.
