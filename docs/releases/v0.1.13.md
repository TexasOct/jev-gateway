# JEV Gateway 0.1.13

This release simplifies the strategy canvas and question editor so ordered routing
rules are easier to follow and change.

- Question answers share one result connection, with a separate classification
  failure path. Adding criteria no longer creates duplicate entry wires.
- Rules continue vertically and show their conditions and destinations directly.
  Automatic arrangement aligns model groups with their first matching rules.
- Cards use a quieter appearance and compact ports. Connections remain accessible
  when saved cards are close together or a destination moves to the left.
- The inspector edits one question at a time, preserves unfinished input between
  questions, and explains AND across questions and OR within selected values.
- Rule editing puts the destination first. Model editing waits for pending layout
  saves, and the model chooser remains available through the add-node menu.

The release also records the accepted local task-type routing configuration,
updated project documentation and the ongoing supplier subscription onboarding
design. The example routing configuration is optional; installing this release
does not change an existing deployment's strategy or suppliers.

Validation includes 448 frontend unit tests and 410 related browser cases, frontend
lint/build and TypeScript checks. Tagged publication additionally requires the
existing package-validation, backend and Ubuntu/macOS installed-wheel gates.

Python 3.12+ is required. The wheel includes the Dashboard and requires no Node.js
on the installed host.
