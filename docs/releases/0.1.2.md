# JEV Gateway 0.1.2

首次启动可以先设置管理密钥、进入 Dashboard，再配置供应商和模型。默认配置只包含策略方案；尚未配置模型时，对话接口返回 `503 setup_incomplete`，控制台和网关进程继续可用。终端部署可使用 `jev setup` 完成管理密钥设置。

Dashboard 支持供应商密钥写入与轮换。密钥保存在受限权限的 `credentials.json`，配置和管理接口只返回引用与状态。已有 JSON、相邻 `.env` 和进程环境的凭据解析顺序保持兼容。

供应商配置增加可搜索的图标选择和常用供应商模板，图标与协议类型分别保存。模板覆盖常用模型服务和云平台所需的端点、区域及参数，CLI 和 Dashboard 使用同一份供应商预设。

供应商表单、原生选择控件和策略画布修复了布局与交互问题，包括宽屏表单对齐、选择箭头间距和画布取样状态同步。策略配置支持逐步完成，并可设置全局默认路由。

安装器更新 Release wheel 后会重启原本运行中的、归属已验证的受管理网关，并等待健康检查。原本停止的网关保持停止；重复安装与普通卸载保留运行配置、凭据和记录。

本版本发布安装器、wheel 及各自的 SHA256 校验文件，共四个文件。wheel 包含 Dashboard，安装和运行不需要 Node.js。

固定版本安装可先下载、审阅并校验脚本：

```sh
curl -fL --retry 3 -o install.sh https://github.com/TexasOct/jev-gateway/releases/download/v0.1.2/install.sh
curl -fL --retry 3 -o install.sh.sha256 https://github.com/TexasOct/jev-gateway/releases/download/v0.1.2/install.sh.sha256
# Review install.sh before running it.
# macOS:
shasum -a 256 -c install.sh.sha256
# Linux: use sha256sum -c install.sh.sha256 instead.
sh install.sh --version 0.1.2 --yes
jev --version
jev doctor
```

同一发布者提供的校验文件用于核对下载一致性，并非独立签名。安装、配置与卸载说明见 [local-install.md](https://github.com/TexasOct/jev-gateway/blob/v0.1.2/docs/local-install.md)。
